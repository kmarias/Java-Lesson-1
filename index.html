LESSON 01

Looping Statements in Java

A loop runs a block of code again and again while a condition is true. Loops save time, reduce errors and keep code readable.

01Objectives

  2. Discuss how each looping statement works.
  3. Demonstrate how looping statements work by tracing code.
  4. Apply looping statements in creating programs.

02Discussion & Examples

What is a looping statement?

A loop is a sequence of statements executed repeatedly, zero or more times, as long as a given condition is satisfied. Imagine printing the numbers 1 to 1,000. Without a loop that is 1,000 println statements. With a loop it is three lines.

Every loop has 3 ingredients. A starting value (initialization), a condition that decides whether to keep going, and an update that moves the loop toward stopping. Forget the update and you get an infinite loop.

The do/while loop is a variant of the while loop. It executes the code block once before checking the condition, then repeats as long as the condition is true.

3. The for loop

When you know exactly how many times you want to loop, use a for loop. All three ingredients sit together in one line.

4. break and continue

break jumps out of the loop completely. You have seen it in switch; it works in loops too.
continue skips the rest of the current iteration and moves on to the next one.

break and continue also work in while loops. In a while loop with continue, remember to update the counter before continue, or the loop gets stuck.

Which loop should I use?

SituationBest loop
You know the number of repetitions (print 1–100, process 10 scores)for
You repeat until something happens, and it may not need to run at all (read until the user types 0)while
The body must run at least once (show a menu, then ask "Again? y/n")do/while

Methods in Java

A method is a named block of code that runs only when it is called. Write it once, then call it as many times as you need.

What is a method?

  • A method is a block of code that only runs when it is called.
  • It is a collection of statements grouped together to perform an operation.
  • You can pass data, called parameters, into a method.
  • Methods are also known as functions.
  • Why use methods? To reuse code: define it once, use it many times.

Creating and calling a method

A method must be declared inside a class. Java already gives us methods like System.out.println(), but we can create our own. To call a method, write its name followed by parentheses and a semicolon. A method can be called many times.

myMethodthe name of the method
staticthe method belongs to the Main class, not to an object of the class
voidthe method does not return a value

Parameters and arguments

Information can be passed to methods as parameters. Parameters act as variables inside the method. They go inside the parentheses after the method name; separate several parameters with commas.

Parameter: the variable in the method definition. Here: fname.
Argument: the actual value passed when calling. Here: "Angela", "Mark", "Cristelle".

Multiple parameters. You can have as many as you like. The arguments must be in the same order and of matching types.

Return values

void means the method returns nothing. To send a value back, replace void with a data type (int, double, String…) and use the return keyword.

Storing the result in a variable is recommended, because it is easier to read and maintain.

A method with if...else

Method overloading

With method overloading, multiple methods can have the same name with different parameters (different number or types). Java picks the right version based on the arguments.

Not overloading: two methods that differ only in return type, like int f(int x) and double f(int x). That is a compile error.

Scope

In Java, a variable is only accessible inside the region where it is created. This is called scope.

A block can be on its own or belong to an if, while or for. A variable declared in a for header (like int i) exists only inside that loop.

LESSON 03

One-Dimensional Arrays

An array stores a fixed-size, ordered collection of values of the same type under one name. Each value is reached by its index.

01Objectives

By the end of this lesson, you should be able to:

  1. Understand the fundamental concepts of arrays in Java.
  2. Apply different techniques for working with arrays effectively.
  3. Analyze and solve common programming problems using arrays.

02Discussion & Examples

Why arrays?

Suppose you need the number of days in each month. Without arrays you would need 12 variables: jan, feb, mar… With an array, one name holds all 12 values.

An array is a group of like-typed variables referred to by a common name. Think of it as a row of numbered lockers: the locker number is the index and what is inside is the element.

Indexes start at 0. An array with 12 elements has indexes 0 to 11. The last index is always length - 1.

Declaring array variables

Creating an array

Declaring only makes the variable. To create the actual array, use new with a size. The elements start with a default value: 0 for numbers, false for boolean, null for String.

Processing arrays with loops

Arrays and for loops go together. Use array.length instead of a hard-coded number so the loop still works if the array size changes.

The enhanced for loop (for-each)

When you only need to read every element and don't need the index, the for-each loop is shorter: "for each num in array".

Common error: ArrayIndexOutOfBoundsException happens when you use an index < 0 or >= length, for example i <= arr.length instead of i < arr.length.

What is a 2D array?

  • An array of arrays. It basically looks like a table with rows and columns.
  • It can only store one data type at a time.
  • It is useful when you want to store data in tabular form, like a table of student grades.

Nested for loop

A nested for loop is a for loop inside another for loop. The outer loop walks the rows; for each row, the inner loop walks all the columns. The inner loop finishes completely before the outer loop moves on.

Note: myNumbers.length is the number of rows (2). myNumbers[row].length is the number of columns in that row (4, then 3). Rows can have different lengths. If your array has a fixed, known size you can use numbers instead, but .length is safer.
